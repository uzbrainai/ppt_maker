## New macros these suggest (not yet built)
- **`radial`** — a ring/donut split into N labeled segments with callouts (templates 01/03/09/11).
- **`funnel`** — stacked funnel stages with side notes (template 04).
- **`venn`** — two/three overlapping shapes for relationships/comparison (06).
- **`columns`** — clean multi-column text layout, 2–3 columns with a header band (02/05/10/12).

Common theme across all: green palette, generous whitespace, simple geometry, a
header band, and one diagram per slide.
